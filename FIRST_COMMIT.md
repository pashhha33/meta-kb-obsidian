# Что сделать сразу после создания репозитория

```bash
cd meta-kb-obsidian
git init
git add .
git commit -m "init: структура репозитория + инструкции + стартовый PHASE.md"
git branch -M main
git remote add origin <URL-вашего-репозитория>
git push -u origin main
```

После этого скажите Чату: **«прочитай репо»**
