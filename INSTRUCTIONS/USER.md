# Правила для пользователя

1. Ты — единственный, кто коммитит в репозиторий.
2. Чат никогда ничего не пишет в репо — только предлагает текст.
3. Агент пишет только в свою песочницу. Ты переносишь файлы и коммитишь.
4. Всегда держи `PHASE.md` актуальным.
5. Когда Чат предлагает обновление `PHASE.md` или новый ADR/итерацию — копируй и коммить.
6. Когда Агент отдал артефакты — перенеси их в нужные папки и закоммить.
7. Для продолжения работы достаточно сказать Чату:
   - «прочитай репо»
   - «следующая итерация»
   - «следующая фаза»
   - «подготовь задание агенту»
   - «зафиксируй итерацию»
