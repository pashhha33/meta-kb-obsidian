# ADR-001: Переименование hierarchical-category → category

**Статус:** accepted  
**Дата:** 2026-11-04  
**Итерация:** ITER-2026-11-04-1  
**Контекст:** DISCOVERY поверх REFERENCE/

## Контекст

В метамодели Second Brain PKB один из десяти встроенных метатипов называется `hierarchical-category`.  
Имя длинное, а иерархичность уже выражается отношением `parent`. Специальный `type_prefix` (`hierarchical-cat`) усложняет правила без явной пользы.

## Решение

Переименовать встроенный метатип:

- `type`: `hierarchical-category` → `category`
- `type_prefix`: становится обычным `category` (специальный случай удаляется)
- Фиксированный `id` оставляем прежним: `01a17d3b-4a06-7991-b54e-9352cde369c0`
- Русское имя: «Категория» (вместо «Иерархическая категория»)

## Последствия

### Плюсы
- Короче и понятнее
- Убирается единственный специальный случай `type_prefix`
- Ближе к привычной терминологии

### Минусы / риски
- Расхождение с исходным Reference (нужно явно фиксировать в changelog и в ontology)
- Все упоминания в будущих правилах, отношениях и валидаторах должны использовать новое имя
- При миграции существующих vault’ов потребуется rename файлов и обновление frontmatter

### Не затрагивается
- Отношения `parent`, `category-domain`, `object-category` — ключи пока оставляем
- Слой `classification` и общая трёхслойная модель

## Связанные решения
- Будет учтено при первом заполнении `metamodel/types.md` и `metamodel/ontology.md`
