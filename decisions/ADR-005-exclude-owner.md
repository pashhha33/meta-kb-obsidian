# ADR-005: Исключение свойства `owner` из обязательных

**Статус:** accepted  
**Дата:** 2026-11-05  
**Итерация:** ITER-2026-11-04-1  
**Контекст:** DISCOVERY

## Контекст

В Reference `owner` — обязательная строка (INV-11), default `human`, не ссылка.  
Исполняемой семантики (ACL, фильтрация, связь с `person`) нет — поле информативное.

## Решение

Исключить `owner` из набора обязательных свойств объекта.

Обязательные свойства v1 (9 штук):

`id`, `type`, `defined_by`, `title`, `aliases`, `layer`, `status`, `created_at`, `updated_at`

## Последствия

- Меньше шума в frontmatter.
- Расхождение с Reference INV-11 — фиксируется этим ADR.
- Если позже понадобится «ответственный», вводится отдельное свойство (например `responsible: link`) через новый ADR, без возврата к обязательной строке `owner`.
