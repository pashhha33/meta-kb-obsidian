# ADR-004: Временные метки и объём глав/книги

**Статус:** accepted  
**Дата:** 2026-11-04  
**Итерация:** ITER-2026-11-04-1  
**Контекст:** DISCOVERY поверх REFERENCE/

## Контекст

В Reference нет универсальных свойств времени создания/изменения.  
Для глав и книг нужен автоматический подсчёт объёма и обновление связанных данных.

## Решение

1. **Обязательные временные метки** у любого объекта:
   - `created_at` (datetime, UTC) — при создании, неизменяемо;
   - `updated_at` (datetime, UTC) — при каждом значимом изменении.

2. **Хранение** — всегда UTC.  
   **Отображение** — настройка плагина `datetimeDisplay`: `local` (по умолчанию) / `utc` / `fixed-offset`.

3. **Объём главы:** только `char-count` — чистый текст тела (без markdown).

4. **Объём книги:** `char-count` (сумма глав) + `author-sheets` (`char-count / 40000`).

5. При любой манипуляции с главой книга пересчитывает объём и обновляет `updated_at`.

## Последствия

### Плюсы
- Однозначные данные при синхронизации между машинами
- Удобное локальное отображение
- Автоматический объём без ручного ввода

### Риски
- Нужен стабильный парсер «тело → чистый текст»
- Пересчёт книги при частых правках глав
