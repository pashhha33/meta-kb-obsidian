# ADR-003: Поведение обёртки image

**Статус:** proposed  
**Дата:** 2026-11-04  
**Итерация:** ITER-2026-11-04-1

## Контекст

Reference фиксирует, что `image` — обёртка над файлом (INV-23, INV-24).  
Требуется определить конкретное поведение в теле заметки, при наведении, при создании и при интеграции с Bases.

## Решение

Принять правила C-IMG-01…C-IMG-07:

- Embed обёртки показывает изображение.
- Bases различает метаданные и изображение.
- Hover → открыть / создать обёртку.
- Создание — с выбором источника (миниатюры / буфер / путь).
- **Один файл = одна обёртка** (запрет дублей).
- Роли файла — мультивыборное свойство `roles` на обёртке.
- При удалении обёртки — обязательный запрос: удалять файл или нет.
