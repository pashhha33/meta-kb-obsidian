# ADR-002: Создание и навигация глав (chapter)

**Статус:** accepted  
**Дата:** 2026-11-04  
**Итерация:** ITER-2026-11-04-1  
**Контекст:** DISCOVERY поверх REFERENCE/

## Контекст

Reference описывает только базовое создание `chapter` из отношения `chapter-of` (тип подставляется автоматически).  
Требуется более удобный рабочий процесс: быстрое создание последовательности глав, навигация между ними, предсказуемые имена по умолчанию и корректная работа с «дырками» в нумерации.

## Решение

Ввести специализированное поведение для типа `chapter` (правила C-CH-01…C-CH-06):

- При создании/обновлении запрашиваются: книга (`chapter-of`), номер (`position`), имя (`title`).
- Имя можно пропустить.
- Дырки в нумерации разрешены.
- Если главы с данным `book + position` ещё нет и имя пропущено → `title = "Глава - {N}"`.
- Если глава уже существует:
  - явное имя → заменяет `title` и `aliases[0]`;
  - пропуск имени → существующее имя сохраняется.
- В интерфейсе главы — навигация «← Предыдущая / Книга / Следующая →».
- При отсутствии соседней главы предлагается создать её (с тем же правилом имени).

## Последствия

### Плюсы
- Минимальное трение при ведении книги по главам
- Предсказуемые имена и порядок
- Навигация всегда под рукой
- Дырки не ломают процесс

### Минусы / риски
- Специальное поведение пока только для одного типа
- Нужна аккуратная валидация уникальности `position` внутри книги
- Требует UI-компонента в плагине

### Альтернативы, которые отклонены
- Полностью ручное создание без мастера
- Автоматическое создание соседних глав без подтверждения
- Запрет дырок в нумерации
