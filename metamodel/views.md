# Views & Representations

> Статус: в разработке (DISCOVERY)

## Представление: Chapter Navigation

Для объектов `type: chapter` плагин предоставляет:

1. **Command palette / контекстное меню**
   - «Предыдущая глава»
   - «Следующая глава»
   - «Перейти к книге»

2. **UI-блок в заметке** (рекомендуемый вариант — виджет под заголовком или в боковой панели):

   ```
   [← Предыдущая]  [Книга]  [Следующая →]
   ```

3. **В агрегате книги** (вид «Оглавление»):
   - список глав, отсортированный по `position`;
   - кнопка «+ Добавить главу» → вызывает C-CH-01.

   ## Представление: Image Wrapper

1. **Embed в теле заметки**  
   `![[image_{id}]]` → рендерится как само изображение (`attachment`).

2. **Hover-overlay**  
   - Иконка «Открыть обёртку» / «Создать обёртку» (см. C-IMG-03).

3. **Диалог создания обёртки**  
   - Поле имени  
   - Выбор источника (миниатюры необёрнутых файлов / буфер / путь)

4. **Bases**  
   - Колонка «метаданные» → свойства объекта  
   - Колонка «изображение» → файл из `attachment`
