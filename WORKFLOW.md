# Рабочий процесс проектирования и реализации метамодели + плагина Obsidian

## Роли

| Роль       | Права                              | Ограничения                                      |
|------------|------------------------------------|--------------------------------------------------|
| **Чат**    | Читает репозиторий                 | Не создаёт файлы. Только предлагает текст        |
| **Агент**  | Читает репозиторий                 | Реализует только в песочнице                     |
| **Пользователь** | Единственный, кто коммитит    | Переносит артефакты Агента вручную               |

## Фазы

| Код            | Название                      |
|----------------|-------------------------------|
| INIT           | Инициализация                 |
| DISCOVERY      | Анализ / Discovery            |
| DESIGN-META    | Проектирование метамодели     |
| DESIGN-PLUGIN  | Проектирование плагина        |
| IMPL-META      | Реализация метамодели         |
| IMPL-PLUGIN    | Реализация плагина            |
| INTEGRATION    | Интеграция и тестирование     |
| EVOLVE         | Рефакторинг / Эволюция        |
| STABLE         | Стабилизация                  |

## Итерации

Формат: `ITER-YYYY-MM-DD-N`  
Пример: `ITER-2026-11-04-1`

Всегда актуальная информация — в файле `PHASE.md`.

## Цикл работы

1. Пользователь говорит Чату «прочитай репо» / «следующая итерация» / «следующая фаза».
2. Чат анализирует репозиторий и выдаёт готовый markdown (обновление PHASE.md, ADR, задание Агенту и т.д.).
3. Пользователь копирует текст в нужные файлы и коммитит.
4. Пользователь говорит Агенту «выполни задание».
5. Агент реализует в песочнице и возвращает файлы/диффы.
6. Пользователь переносит артефакты, коммитит, обновляет PHASE.md.
7. Повторять.

## Команды

### Для Чата
- `прочитай репо` / `статус` / `где мы`
- `следующая итерация`
- `следующая фаза` / `перейти к фазе <код>`
- `зафиксировать` / `завершить итерацию`
- `подготовить задание для агента`
- `анализ reference`
- `предложить ADR`

### Для Агента
- `выполни задание`
- `статус реализации`
- `исправь по замечаниям`
