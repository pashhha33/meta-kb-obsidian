## Цель

Виджет Meta KB Properties становится **формой по типу**: показывает эффективные
поля типа, а не только те ключи, что уже есть в frontmatter.

## Сделано

- `plugin/src/core/form.ts` — `buildForm(typeValue, frontmatter)`: слияние
  эффективной схемы (`effectiveSchema`) с фактическим frontmatter.
  - отсутствующие поля эффективной схемы попадают в форму как пустые строки
    (`missing`), это и превращает виджет в форму;
  - ключи, которых нет в контракте, показываются и перечисляются в `unknown`;
  - системные поля не показываются пустыми (их ставит плагин, не пользователь);
  - `filled` / `total` — прогресс заполнения без системной секции.
- `plugin/src/ui/PropertiesView.ts`:
  - секции строятся по `buildForm`, а не по ключам frontmatter;
  - секция «Вычисляемые» показывает живой `char-count` из тела заметки и
    `author-sheets` для книги (в frontmatter не пишутся);
  - в шапке — счётчик «заполнено/всего»;
  - `render()` стал асинхронным (нужно чтение тела), добавлен `renderSeq` против
    гонок: устаревший кадр не рисуется;
  - поле выбора ссылок/медиа получает `target_type` отношения (`image` для
    media) — как и раньше.
- `plugin/src/ui/FieldRow.ts` — модель получила `absent`, строка пустого поля
  помечается классом `is-absent`.
- `plugin/src/settings.ts` — новая настройка `authorSheetChars` (default 40000,
  `metamodel/plugin-settings.md`).
- `plugin/styles.css` — стили пустых строк формы, счётчика и **UI выбора
  ссылок/медиа** (`meta-kb-chips`, `meta-kb-suggest-*`). В прошлом срезе разметка
  была добавлена без стилей — исправлено.
- `plugin/tests/form.test.ts` — 8 тестов на построение формы; всего 58.

## Проверенные сценарии (тесты)

- тип не распознан → показываются только присутствующие ключи;
- `person` без данных → `birth-date`, `occupation` видны пустыми; `isbn`,
  `box-office-worldwide` отсутствуют; `chapter-of` отсутствует;
- `occupation: [politician]` → появляются `office`, `party`; `[writer]` →
  `specialization`; `member-of` появляется только при триггере FE-02;
- `book` + `format: audiobook` → `attachment`, `duration`;
- `char-count` не попадает в `missing` (вычисляемое поле не заполняют вручную).

## Принятые решения

1. **Пустые строки, а не отдельная кнопка «добавить поле».** Форма по типу должна
   показывать набор полей; приглушённая пустая строка + ✎ = заполнить. Секции
   сворачиваются, системная свёрнута по умолчанию.
2. **Вычисляемые поля не пишутся в frontmatter.** `char-count`/`author-sheets`
   считаются на лету из тела активной заметки. Запись при сохранении тела
   (properties.md §4, C-CH-10) — следующий срез, вместе с суммированием глав
   книги (`book.char-count` = сумма глав требует чтения тел всех глав).
3. **Системные поля только присутствующие.** Пустая строка `created_at` или
   `defined_by` бессмысленна: их проставляет плагин при создании объекта.
