**Статус:** completed

## Цель

Срез A1 по ADR-003 / C-IMG: **рабочий процесс привязки изображения** — создание
обёртки с выбором файла вместо ручного вписывания пути.

## Сделано

**Контракт (schemaVersion 1.1.0 → 1.2.0):**

- ADR-007: поле `required_by_type` у свойства; `attachment` получает
  `required_by_type: { "image": "always" }` — INV-24 стал машиночитаемым;
- `metamodel.schema.json`: `required_by_type` в обеих схемах свойств;
- G2 (`tools/schema-check.mjs`): ключи `required_by_type` обязаны ссылаться на
  существующие типы, значения — входить в enum.

**Код (`src/core`, чистая логика):**

- `attachment.ts` — `normalizeAttachmentPath` (прямые слэши, декодирование
  процента, без `./`, `/`, `//`, якоря и query по `plugin-settings.md`),
  `fileExtension`, `isImagePath`, `buildAttachmentIndex` (включая поиск
  нарушений C-IMG-05), `wrapperForPath`, `unwrappedImagePaths`,
  `decideAttachment` (**решение** о привязке: свободен / занят чужой обёрткой /
  пустой путь), `buildImageWrapperPlan`;
- `metamodel.ts` — `requiredFor(propertyKey, typeValue)` с поиском по цепочке
  `extends`.

**UI:**

- `ui/modals/ImageFilePickerModal.ts` — галерея **миниатюр** через
  `getResourcePath`, пометка «обёрнуто», ручной ввод пути, кнопка
  «Открыть существующую»; режимы `create-wrapper` (спрашивает имя) и
  `pick-attachment` (только путь);
- команда **`Create image wrapper`** — галерея + создание объекта `image` с
  обязательным `attachment` (C-IMG-04);
- строка **«Вложение»** в виджете открывает тот же выбор файла вместо
  текстового поля; свой путь разрешён, чужой блокируется (C-IMG-05);
- индекс `attachment → image` пересобирается вместе с Registry;
- стили галереи.

**Тесты:** +16 (attachment, `requiredFor`); всего 105.

## Принятые решения

1. **Решение о привязке вынесено из модалки в `decideAttachment`.** Инвариант
   C-IMG-05 — главное правило среза, и он не должен жить в UI-коде, недоступном
   тестам. Модалка только показывает результат решения.
2. **Один общий диалог на два сценария.** Создание обёртки и выбор значения
   `attachment` отличаются лишь наличием поля имени, поэтому это один компонент
   с режимом, а не две почти одинаковые модалки.
3. **Миниатюры через `getResourcePath`.** Галерея «необёрнутых изображений»
   из C-IMG-04 реализована как список всех изображений хранилища с пометкой
   «обёрнуто»; отдельный фильтр «только необёрнутые» не нужен — занятые видны и
   заблокированы решением.
4. **`attachment` в контракте остаётся `string`.** Это путь, как и написано в
   `properties.md`; ссылкой (`media`) он быть не может — иначе нарушился бы
   INV-23 (media указывает на обёртку, а не наоборот).
