# ITER-2026-11-13-1

**Фаза:** IMPL-PLUGIN
**Статус:** completed
**Дата:** 2026-11-13 — 2026-11-14

## Цель

Слой данных плагина: Loader, Registry и Schema (эффективные поля с
field-expansion), подключение Registry к UI и автообновление `updated_at`.

## Сделано

- `plugin/src/core/schema.ts` — `effectiveSchema(type, frontmatter)`: `extends` +
  field-expansion (union). **FE управляет формой, не допустимостью**
  (field-expansion.md §3): поля из `adds_*` появляются по триггеру.
- `plugin/src/core/loader.ts` — `toObjectRecord(path, frontmatter, body)`.
- `plugin/src/core/registry.ts` — индекс `id → ObjectRecord`, `resolveLink`,
  `all()`.
- `plugin/src/core/derived.ts` — `isSignificantChange`, `withUpdatedAt`,
  `computeCharCount`, `computeAuthorSheets`.
- `plugin/src/core/suggest.ts` — `suggestLinks`, `linksToCandidates`,
  `candidatesToValue`.
- `plugin/src/core/metamodel.ts` — данные для Schema (`CORE_TYPES`,
  `ALL_PROPERTIES`, `ALL_RELATIONS`, `FIELD_EXPANSION`, `typeChain`, `isKnownType`).
- `plugin/src/main.ts` — Registry из `metadataCache` всех md-файлов, пересборка
  по `changed`/`resolved`/`delete`/`rename` (debounce 300 мс); `getRegistry()`.
- `plugin/src/ui/modals/suggestSelect.ts` — общий селектор кандидатов.
- `LinkModal`/`MediaModal` — рабочие модалки выбора из Registry (одиночный и
  множественный), запись канонической ссылкой `[[{type}_{id}|{title}]]`.
- `PropertiesView` — передаёт `suggest` (target_type отношения / `image` для
  media); значимое изменение поля двигает `updated_at` (ADR-004).
- `plugin/tests/` — +14 тестов; всего 49, зелёные.

## Не вошло (следующие срезы)

- Виджет показывает только присутствующие ключи; эффективные поля типа
  (пустые строки для обязательных/применимых) — следующий срез.
- Вычисляемые `char-count`/`author-sheets` при сохранении тела (сейчас только
  функции в `derived.ts`).
- Инкрементальное обновление Registry (пока полный пересбор, debounce 300 мс).
- Suggest для link/media не ограничивает глубину/циклы — только типом цели.
