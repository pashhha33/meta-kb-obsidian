## Цель

Слой данных плагина: Loader, Registry и Schema (эффективные поля с
field-expansion) как чистая логика в `plugin/src/core/`, с тестами.

## Сделано

- `plugin/src/core/schema.ts` — `effectiveSchema(type, frontmatter)`: базовые
  свойства/отношения по цепочке `extends` + добавление по field-expansion (union).
- `plugin/src/core/loader.ts` — `toObjectRecord(path, frontmatter, body)`.
- `plugin/src/core/registry.ts` — индекс `id → ObjectRecord`, разрешение ссылок.
- `plugin/src/core/metamodel.ts` — экспорт данных для Schema (`CORE_TYPES`,
  `ALL_PROPERTIES`, `ALL_RELATIONS`, `FIELD_EXPANSION`, `typeChain`, `isKnownType`).
- `plugin/tests/` — добавлены `schema.test.ts`, `loader.test.ts`, `registry.test.ts`.

## Не вошло (следующие срезы)

- Подключение Registry к ui (модалки link/media с suggest).
- Автообновление `updated_at` и вычисляемые `char-count`/`author-sheets`.
- Инкрементальное обновление Registry при изменении vault (пока пересборка).

## Критерии приёмки

- `node tools/schema-check.mjs` → OK
- `cd plugin && npm run build` → 0
- `cd plugin && npm test` → все тесты зелёные (34+)
